Production notes

  • Record each segment separately and cut them together. Phone at eye level and a quiet room are enough for the on-camera parts.
  • Use the deployed portal, not localhost, so the address bar shows Cloud Run.
  • Caption the numbers as they're spoken: 74% vs 55%, 0.82°F vs 1.04°F, 15 vs 20 days.
  • Agent segment: rehearse both prompts and record several takes. Gemini's wording changes run to run, so the voice-over describes what the agent does, never its exact reply. Keep a screenshot of a good run as a fallback.
  • Timing: the spoken words run about 2:42 at a normal pace. The striped end of the timeline is the time left for typing, clicks and pauses. If a pace pushes past 3:00, the total turns red.
